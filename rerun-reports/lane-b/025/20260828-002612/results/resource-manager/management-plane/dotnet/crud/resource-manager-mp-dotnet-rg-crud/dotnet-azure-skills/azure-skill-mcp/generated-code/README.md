# Azure Resource Group Manager

This .NET 8 console sample uses the current Azure management-plane SDK to create,
list, retrieve, tag, and delete an Azure resource group.

## Required NuGet packages

```powershell
dotnet add package Azure.Identity --version 1.21.0
dotnet add package Azure.ResourceManager --version 1.14.0
```

The project file already contains these package references. It does not use the
legacy `Microsoft.Azure.Management.*` packages.

## Configuration and execution

`DefaultAzureCredential` tries its supported credential chain. For local
development, sign in with a supported developer credential and set the target
subscription:

```powershell
$env:AZURE_SUBSCRIPTION_ID = "<subscription-id>"
$env:AZURE_RESOURCE_GROUP_NAME = "rg-sdk-demo" # Optional; a unique name is generated by default.
dotnet run
```

The authenticated identity needs permission to read, create, update, and delete
resource groups in the subscription, such as the Resource Group Contributor
role at subscription scope.

> Running the sample changes a real Azure subscription. The delete operation is
> awaited, but an interruption or failure before deletion can leave the resource
> group in place.
