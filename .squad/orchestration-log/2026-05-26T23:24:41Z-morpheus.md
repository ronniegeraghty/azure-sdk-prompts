## Review Pattern Learned

When PRs evolve through multiple commits that reverse or narrow scope:
- Document final state only; don't reference intermediate experiments
- "What shipped" sections must describe final diff, not earlier attempts
- Test result claims must be achievable with shipped code
- Use final commit SHA for all memory artifacts
