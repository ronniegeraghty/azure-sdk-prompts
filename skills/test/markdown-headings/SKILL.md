# Markdown Heading Best Practices

When writing markdown files:

- Use a single `#` for the document title (H1)
- Use `##` for major sections (H2)
- Use `###` for subsections (H3)
- Do NOT skip heading levels (e.g., don't jump from H1 to H3)
- Each markdown file should have exactly ONE H1 heading
- Headings should have a blank line before and after

Example:

```markdown
# Document Title

## Section One

Some content here.

### Subsection

More details.

## Section Two

Another section.
```
